# Đất Cảng – Hệ thống quản lý khách (Sale)

Web nội bộ chạy trên Google Apps Script, dùng Google Trang tính làm cơ sở dữ liệu.

- `Code.gs`: máy chủ (đăng nhập, lead, giai đoạn, nhật ký). `DB_ID` là chỗ điền ID Trang tính, không lưu ở repo.
- `Index.html`: giao diện.
- `test/sim.js`: kiểm thử giả lập: `node test/sim.js`.

**Quy tắc:** repo chỉ chứa mã nguồn. Không đưa dữ liệu khách, mật khẩu, ID Trang tính thật, token vào repo.
